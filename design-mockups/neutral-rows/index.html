알림 설정

내 연락처

팀 링크는 카톡 · 전화 색 아이콘이 붙어 있어요. 편지 쓰기의 연락처 고르기(Contact Pick)와 같은 아이콘으로 맞춘 안도 같이 찍었어요.

배지 · 인증

"인증하기" 줄 오른쪽 "시작하기"를 바꾼 세 가지. C1 글자 없이 › 만 · C2 받을 리프(위 타일과 겹쳐요) · C3 "인증 전" 상태.

D2 다듬기 · 체크 원 작게 + 타일 흐리게

인증한 타일은 바탕을 더 옅게, "학력 · 받았어요" 글자를 45%로 흐리게. 진한 체크 원은 그대로 진하게 남겨서 "끝났다"가 먼저 보여요. 원 크기만 다른 두 가지 · 왼쪽부터 섞인 상태 · 모두 인증 · 인증한 줄을 누르면 뜨는 시트.

원 32 체크 16 · 아직 안 한 타일 아이콘 원(40)보다 한 단계 작게

원 28 체크 14 · 더 가볍게

배지 · 인증 · 인증한 뒤 (B + C1 기준)

팀 링크는 인증한 뒤 화면이 있어요(줄마다 체크 + 아래 항목별 카드 "경희대학교 졸업 · ✓ 인증 완료 · 변경 / 인증 취소"). 우리 데모도 상태는 있지만(타일 아이콘이 체크로, 오른쪽 "인증됨") 받은 리프가 사라지고, 인증한 줄을 누르면 빈 인증 폼이 다시 열려요. 아래 안은 모두 인증한 줄을 누르면 "인증한 내용" 시트가 떠요. 확인 중은 회색 "확인 중"만, 아직 안 한 줄은 › 만.

D1 · 타일 흐리게 + 체크 말씀하신 안. 인증한 타일은 원래 아이콘 그대로 흐리게(45%) + 오른쪽 위 진한 체크 20, 아래 "+20 받음". 줄은 "✓ 인증됨" + 인증한 내용

D2 · 타일 진한 체크 흐리지 않고 아이콘 자리가 진한 체크 원, 아래 "받았어요"

D3 · D1 + "인증한 배지" 묶음 따로 팀 링크처럼 인증한 것과 할 것을 나눠요. 모두 인증하면 "인증하기" 묶음은 사라져요
