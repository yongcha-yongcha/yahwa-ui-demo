하단 버튼 영역

두 군데 모두 아래 고정 버튼 위로 내용이 비치거나 잘려 보여요. 원인은 두 가지예요. ① 꺼진 버튼이 투명도 45%(#features button:disabled{opacity:.45})라 버튼 뒤 내용이 그대로 비쳐요. ② 버튼 위 그라데이션이 16px로 짧아서, 바로 위를 지나는 글자가 다 지워지기 전에 버튼에 닿아요. 폰 안을 스크롤해서 내용이 버튼 뒤로 지나가게 해 보세요.

1. 취향 설정 · 저장하기

꺼진 버튼은 투명도 대신 불투명한 연한 회색으로, 버튼 위에는 40px 페이드를 둬서 내용이 버튼 근처에 오기 전에 완전히 사라지게 해요.

지금투명도 꺼짐 · 짧은 페이드

버튼 자체가 45% 투명이라 뒤의 “인증한 인연 먼저 보기” 글자와 체크 아이콘이 버튼 위로 비쳐요. 위쪽 16px 페이드는 금방 끝나요.

opacity .45 · fade 16px → 28%

D1불투명 꺼짐 + 40 페이드추천

꺼진 버튼 = cool-neutral 100 꽉 찬 바탕 + 회색 글자(투명도 1). 버튼 위 40px에서 종이색으로 완전히 덮여, 내용은 버튼에 닿기 전에 사라져요.

disabled bg #E3E7EA · opacity 1 · fade 40px

D2D1 + 살짝 흐림

페이드 구간에 흐림 8을 더해 지나가는 글자가 번지며 사라져요. 머리 줄 흐림과 같은 결이지만 차이는 작아요.

D1 + backdrop blur 8 (mask 40px)

2. 소개 미리보기 · 이 소개로 완성하기

지금은 스크롤 영역이 버튼 위 108px에서 끝나 내용이 칼로 자른 듯 끊겨요. 스크롤 영역을 화면 끝까지 늘리고, 버튼 위 48px 페이드로 내용이 자연스럽게 숨겨지게 해요. 마지막 내용은 버튼 위까지 올라올 수 있게 아래 여백을 둬요.

지금딱 잘림

“담배 · 술” 카드가 반쯤 잘린 채 멈춰 보여요.

F1끝까지 흐르고 48 페이드추천

내용이 버튼 뒤로 흘러가며 위에서부터 서서히 옅어져요. 버튼은 그대로이고, 끝까지 내리면 마지막 카드가 버튼 위에 온전히 보여요.

적용 범위

  • 꺼진 버튼: 기능 화면의 꺼진 주요 버튼(취향 설정 저장, 시트 저장 · 적용, 편지 답장 등)을 투명도 없이 불투명 회색으로 맞춰요. 글자만 회색이라 “누를 수 없음”은 그대로 읽혀요.
  • 페이드: 아래 고정 버튼이 있는 화면(취향 설정 · 소개 미리보기 · 편지 · 글 상세 입력창)에 같은 토큰(페이드 40 · 48)을 써서 한 가지 모양으로 맞춰요.
