편지 대화 · 머리 제목과 위쪽 페이드

편지로 이어진 대화 화면(포근한날님과의 편지)이에요. 앱은 아직 바꾸지 않았어요. 폰은 앱과 같은 크기 · 색으로 다시 그렸고, 위아래로 스크롤해 볼 수 있어요.

지금

  1. 제목이 오른쪽 끝에 작은 파란 글씨로 있어요. 버튼처럼 보이지만 누를 수 없고, 다른 기능 화면(가운데 제목 16 굵게)과 자리도 달라요.
  2. 대화가 길어지면 위에서 뚝 잘려요. 대화 칸이 머리 아래 125에서 시작해서, 말풍선과 사진이 안내 문구 바로 아래에서 직선으로 끊겨요.
  3. “첫 편지로 시작하는 이야기 · UI 시연”이 고정돼 있어요. 내려 읽어도 계속 자리를 차지해요.
  4. 아래 입력칸 위도 같은 방식으로 끊겨요.

개선안

두 안 모두 대화를 화면 맨 위까지 흐르게 하고, 2px 넘게 내리면 다른 기능 화면 머리와 같은 하늘 → 종이색 + 흐림 10 + 아래로 사라지는 페이드가 깔려요. 안내 문구는 대화 맨 위로 들어가 함께 스크롤되고, 입력칸 위에도 40 동안 종이색으로 스며드는 페이드를 둬요.

H1 · 공용 머리처럼 가운데 제목 추천

다른 기능 화면과 같은 머리예요. 뒤로(44) · 가운데 “포근한날님과의 편지” 16 굵게(진한 글자). 누를 수 없는 제목이 파란 글씨로 버튼처럼 보이던 문제가 사라져요.

공용 머리 규칙(Page Header)을 그대로 써서 페이드도 같은 값이에요.

H2 · 상대 얼굴과 이름을 왼쪽에

채팅 앱처럼 뒤로 옆에 상대 사진 32 + 이름 + “편지로 이어진 대화”를 두고, 누르면 상대 프로필로 가요(눌림 0.98 + 회색 배경, 편지 세부 보낸 사람 줄과 같은 반응).

누구와 이야기 중인지 가장 잘 보이지만, 프로필로 가는 길이 하나 늘고 공용 머리와 모양이 달라져요.
