인연 홈 · 카드 아래 넘김 표시

01 / 08을 조금 더 다정하게

카드와 아래 탭, 윗부분(방금 적용한 A안)은 지금 앱 화면 그대로이고, 카드 아래 넘김 표시만 바꿨어요. 오늘 인연 8명은 12시 · 15시 · 18시 · 21시에 두 명씩 열려요. 지금 시연 상태는 12시 두 명만 열려 있어요. 각 폰의 화살표를 눌러 넘겨 보세요(카드 그림은 그대로이고 표시만 바뀌어요).

1번째 인연

지금정리 전

“01 / 08”이 23px로 카드 버튼 글자(인연 열어보기)보다 커서 눈이 먼저 가요. 앞에 0을 붙여 기계 숫자처럼 보이고, 화살표와 숫자 사이가 넓어서 한 덩어리로 안 읽혀요.

A숫자만 가볍게

“1 / 8”로 0을 빼고 15px로 줄여요. 지금 번호만 진하게, 전체 수는 연하게. 화살표도 20으로 줄이고 숫자 곁으로 모아 한 덩어리로 보여요.

B시간대 점추천

숫자 대신 12시 · 15시 · 18시 · 21시마다 점 두 개. 지금 보는 사람은 길쭉한 파랑, 열린 사람은 채운 점, 아직 안 열린 사람은 빈 점이에요. 위의 일정 문구와 그대로 이어져요.

C문장으로

“첫 번째 인연” · “12시에 도착 · 오늘 8명 중”처럼 말로 알려 줘요. 안 열린 사람은 “15시에 만나요”. 가장 다정하지만 글자가 늘어요.

세 안 비교

A바꾸는 양이 가장 적고 어느 화면에나 어울려요. 다만 “8명이 시간대별로 열린다”는 건 여전히 보이지 않아요.
B지금 몇 번째인지, 누가 열렸고 누가 기다리는지를 한눈에 보여 줘요. 바로 위 “매일 12시 · 15시 · 18시 · 21시, 두 명씩”을 그림으로 다시 보여 주는 셈이라 화면이 하나의 이야기로 묶여요. 점이 작아서 숫자보다 정확한 번호는 덜 또렷해요(화면 낭독은 “8명 중 1번째, 12시 인연”으로 읽어요).
C야화 말투와 가장 잘 맞고 따뜻해요. 대신 넘길 때마다 글자가 바뀌어 눈이 자꾸 아래로 가고, 다섯 번째부터는 문장이 길어져요.

추천은 B예요. 숫자가 주던 “몇 번째”에 더해 “언제 열리는지”까지 알려 주면서 카드보다 눈에 덜 띄어요. 숫자를 꼭 남기고 싶으면 A가 가장 안전해요.

세 안 공통

  • 화살표는 지금처럼 Figma Line/Arrow/chevron을 쓰되 24 → 20, 색 --color-fg-secondary. 누르는 영역 44는 그대로예요.
  • 첫 장에서 이전, 마지막 장에서 다음은 흐리게(지금과 같음). 누르면 화살표가 88%로 들어가요(120ms).
  • 표시가 바뀔 때 200ms로 살짝 떠오르며 바뀌어요. 움직임 줄이기 설정이면 흐려졌다 나타나기만 해요.
  • 넘김 표시 자리(카드 아래 66px)와 카드 · 아래 탭 위치는 그대로예요.
