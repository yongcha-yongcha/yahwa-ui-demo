프로필 수정 다듬기

지금 화면은 사진과 이름 아래로 항목이 묶음 없이 이어지기만 하고, 항목마다 지금 값이 잘 안 보여요. 항목을 누르면 가입 단계 화면(2 / 5)으로 넘어가요. 세 시안 모두 짧은 값은 아래 시트에서 바로 고치고, 빈 칸은 "추가하기"로 알려주고, 미리보기를 위에 두고, 하단 네비게이션은 다른 하위 화면처럼 숨겨요. 시안 안의 사진, 항목, 칩, 버튼을 직접 눌러 보세요.

지금 화면에서 하는 일이 비어 보이는 건, 값(직장인)은 저장돼 있는데 목록에 안 그려서 생긴 문제예요. 이것도 같이 고쳐요. 시안 값은 지금 데모 계정(지우) 그대로예요.

지금현재 화면

항목만 길게 이어지고 묶음이 없어요. 하는 일은 저장된 값(직장인)이 안 보이고, 기본 정보는 값 대신 “성격 · 키 · 학력 · 생활”이라는 분류명만 보여요. 사진 버튼과 추가 칸이 글자 ＋를 써요. 하단 네비게이션이 목록을 가려요.

A정돈된 목록추천

대표 사진을 큰 칸으로, 나머지는 작은 칸 5개로 두어 6장 중 몇 장이 찼는지 보여요. 기본 정보 · 일상 · 이야기로 묶고, 항목마다 지금 값을 오른쪽에 보여요. 성별과 생년은 잠금으로 구분해요. 관습에 가장 가까운 안이에요.

B보이는 그대로

목록 대신 상대가 보는 소개 모습 위에서 바로 고쳐요. 위의 “수정 | 미리보기”로 연필과 빈 칩만 사라진 실제 모습을 바로 확인해요. 무드는 가장 잘 살지만 항목이 많아지면 한눈에 훑기는 A보다 어려워요.

C채워 가는 노트

맨 위에 “7개 중 6개”와 남은 한 칸(지금은 사진 2장)을 바로 채우는 버튼을 둬요. 사진은 같은 크기 6칸, 항목은 흰 카드로 묶어요. 빈 칸 계정으로 바꿔 하는 일을 채우면 링이 차오르는 걸 볼 수 있어요. 소개를 끝까지 채우게 하는 힘이 가장 커요.

세 시안 공통

  • 상단 뒤로 · “프로필 수정” 제목 · 오른쪽 “미리보기”(B는 위 전환 버튼). 터치영역 44px을 여백선에 맞췄어요.
  • 짧은 값(하는 일, 키, MBTI, 학력, 종교, 흡연, 음주, 사는 곳)은 아래 시트에서 고르고 “저장”하면 바로 반영돼요. 가입 단계 화면으로 넘어가지 않아요.
  • 긴 글(나의 이야기, 해시태그)과 사진 순서 바꾸기는 지금처럼 각 화면으로 넘어가요.
  • 사진 칸을 누르면 “대표 사진으로 / 다른 사진으로 바꾸기 / 삭제” 시트, 빈 칸은 바로 사진 추가예요. 글자 ＋ 대신 앱 아이콘을 써요.
  • 이름 옆 “기본 프로필 수정 ↗”은 없애고 이름·사는 곳을 기본 정보 묶음 안의 한 줄로 옮겨요.
