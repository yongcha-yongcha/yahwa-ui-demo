  • 고른 표시: 시트 칩 · 해시태그는 진한 채움(cool-neutral-900 + 흰 글자), 이름 고치기의 성별 칸은 진한 테두리(흰 바탕 + 1.5). 이야기 맨 위 "기본 소개 · 필수"는 지금 그대로.
  • 해시태그 분류 줄: 줄 바탕이 화면 바탕과 달라 띠처럼 보이던 걸 화면 바탕과 같게 맞췄어요. 아래 구분선만 옅게(cool-neutral-100).
  • 더 찾아서 고친 것: 스크롤하면 머리 줄 뒤에 깔리는 흐림 막이 흰 배경에서도 하늘색이던 것 → 흰색. 가입 화면들의 진행 막대 · "만 29세" · 날짜 화살표 · 고른 성별 동그라미 · 사진 "대표" 표시 · "이야기 3" · "+ 더하기" · "4 / 5 골랐어요" 숫자와 점 → 뉴트럴. 남은 파랑은 누르는 버튼 · "미리보기" · 일부러 둔 "기본 소개 · 필수"뿐이에요.
  • 하단 띠: 앞 시안에서 버튼 뒤에 보이던 회색 띠는 제가 찍을 때 쓴 흰 배경 방식 탓이었어요(데모엔 없음). 이번엔 시연 도구의 실제 "끄기(흰 배경)"로 찍었어요. 그래서 가입 화면(사진 · 이름 · 이야기 · 해시태그 고치기)은 데모 그대로 종이색 바탕이에요.
  • 그 밖은 앞 시안과 같아요: 연한 파랑 → 쿨 뉴트럴, 카드 · 이야기 상자 · 입력 칸은 회색 바탕(테두리 없음), 파랑은 누르는 버튼 · "미리보기"에만. "고치기" 대신 카드 통째로 누르기, "53자" 빼기, 맨 아래 여백 40.
