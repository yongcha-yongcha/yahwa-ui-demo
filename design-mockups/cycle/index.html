처음 한 번만 알려 주는 관심 툴팁

가입하고 처음 상대 프로필을 볼 때만 "마음이 가면 관심을 보내 보세요."를 알려 주고, 처음 관심을 보낼 때만 아래 마음함 탭에 "보낸 관심은 마음함에 모여요"를 알려 줘요. 두 안내 모두 잠깐 떴다 저절로 사라져요. 한 번 본 계정은 다시 뜨지 않고, 로그아웃했다가 다시 로그인하면 처음처럼 다시 떠요. 오른쪽 단계를 차례로 눌러 보세요. 휴대폰 안 버튼을 직접 눌러도 돼요.

    프로필 안내
    마음함 안내
    • 프로필 안내 "마음이 가면 관심을 보내 보세요." · 아직 관심을 보내지 않은 상대 프로필을 처음 열 때 한 번. 0.6초 뒤 떠서 4초 뒤 저절로 사라져요(화면을 누르거나 관심을 보내면 바로). 다시 안 떠요.
    • 관심 보낼 때 지금 앱의 하트 효과("마음이 한 걸음 가까이", 1.8초)는 그대로 나와요.
    • 마음함 안내 "보낸 관심은 마음함에 모여요" · 처음 관심을 보낼 때 한 번, 하트 효과가 사라져 갈 즈음(1.4초) 떠서 3초 뒤 사라지고, 마음함 하트가 한 번 통 튀어요.
    • 버튼은 상대가 먼저 관심을 보냈으면 "나도 관심 있어요" → "서로 호감이 있어요", 아니면 "관심 보내기" → "관심을 보냈어요".
    • 기억은 계정마다, 로그인한 동안만. 로그아웃하면 지워져서 다시 로그인하면 처음처럼 다시 떠요.
    • 툴팁 바탕은 투명도 없이 Cool Neutral 900, 꼬리도 같은 색이에요.
