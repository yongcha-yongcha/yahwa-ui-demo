# 인연 홈 윗부분 (리프 · 추천 설정) 원칙

간단 벤치마킹 · 사용성 모드 · 2026-11-12. 데이팅 앱 홈·목록 화면 6개를 보고 정리했어요. 스크린샷과 점수표는 생략했어요.

- **P1 제목 줄이 도구 줄이에요.** 화면 제목 오른쪽 같은 줄에 작은 도구 1~2개를 두고, 제목 글자의 세로 가운데에 맞춰요. 제목 아래 줄이나 카드 바로 위에 버튼을 따로 띄우지 않아요.
- **P2 도구는 같은 모양으로 묶어요.** 나란히 놓인 도구는 크기 · 색 · 테두리 유무가 같아야 한 묶음으로 읽혀요. 하나는 글자만, 하나는 테두리 원처럼 섞으면 정리가 안 돼 보여요.
- **P3 추천 설정(조절 아이콘)은 맨 오른쪽 끝이 익숙한 자리예요.** 누르는 영역의 오른쪽 끝을 화면 여백선에 맞춰요.
- **P4 제목 아래 한 줄은 설명용이에요.** 매일 언제 소개되는지 같은 설명은 제목 아래 왼쪽에서 시작해 한 줄로 흐르고, 오른쪽 끝에는 남은 시간 같은 작은 정보 글자만 둬요(버튼이 아니라 글자).
- **P5 재화 잔액은 눌러서 갈 곳이 있을 때만 작게 보여요.** 잔액은 숫자와 아이콘을 붙인 작은 덩어리 하나로 보이고, 화면의 주인공(카드)보다 눈에 띄면 안 돼요.
- **P6 머리와 카드 사이는 비워요.** 카드 윗변 위로 떠 있는 버튼이 없어야 카드가 깔끔하게 시작해요.
