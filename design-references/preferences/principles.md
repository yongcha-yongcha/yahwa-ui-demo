# 추천 설정 모달 · 취향 설정 · 맞춤 인연 추천 원칙

간단 벤치마킹 · 사용성 모드(취향 설정 · 필터) + 확인용(맞춤 추천) · 2026-11-12. 데이팅 앱 필터 · 취향 · 하루 한정 추천 화면 6~8개를 보고 정리했어요. 스크린샷과 점수표는 생략했어요.

## 필터 · 취향 설정
- **P1 필터는 지금 화면 위에 열려요.** 목록 위에서 아래로 열리는 덮개(시트 · 전체 모달)로 열고, 닫으면 보던 카드로 돌아와요. 다른 페이지로 넘어가지 않아요.
- **P2 자주 바꾸는 조건(나이 · 거리)이 맨 위예요.** 나이는 양끝을 끄는 범위 막대, 거리는 한 손가락으로 고르는 막대나 칩이고, 지금 값을 오른쪽에 숫자로 바로 보여 줘요.
- **P3 선택지가 몇 개 안 되면 펼쳐서 보여 줘요.** 3~6개짜리 선택은 칩으로 한눈에 보이게 하고, 선택창(드롭다운)을 열게 하지 않아요.
- **P4 항목마다 지금 값을 보여 줘요.** 목록형이면 항목 이름 아래나 오른쪽에 “상관없음”, “24–34세”처럼 현재 값을 작게 둬요.
- **P5 조건을 너무 좁히지 않게 돕는 장치가 있어요.** “범위를 조금 벗어나도 소개받기”, “꼭 지켜야 하는 조건” 같은 스위치로 엄격함을 따로 고르게 해요.
- **P6 적용은 아래에 고정된 버튼 하나예요.** 바뀐 게 있을 때만 켜지고, 위쪽 한쪽에 “초기화”를 둬요.

## 하루 한정 추천
- **P7 왜 추천했는지가 카드의 주인공이에요.** 사진을 가린 상태에서는 공통점(같이 좋아하는 것 · 같은 태그)을 카드 안에서 가장 크게 보여 줘요.
- **P8 오늘 남은 수와 새로 채워지는 시간을 위에 짧게 보여 줘요.** 재화 잔액은 오른쪽 위 작은 덩어리 하나예요.
- **P9 다음 카드가 옆으로 살짝 보여서 넘길 수 있다는 걸 알려 줘요.** “옆으로 넘겨 보세요” 같은 안내 문장 대신 모양으로 알려요.
- **P10 설명은 “더 알아보기”로 빼요.** 추천 방식 같은 긴 설명은 제목 옆 작은 링크 → 시트로 열고, 화면 아래 접기 상자로 두지 않아요.
- **P11 다 본 뒤에도 빈 화면을 남기지 않아요.** 오늘 몫을 다 쓰면 다음에 채워지는 때와 다시 볼 수 있는 인연을 보여 줘요.
