# 인증 입력 화면 원칙 (간단 벤치마킹, 2026-11-20)

- P1 한 화면에 한 가지 일만: 정보 입력 → 코드 입력 → 끝을 화면으로 나눈다. 단계 표시는 실제로 넘어가는 화면 수와 같아야 한다.
- P2 코드 화면은 "어디로 보냈는지"를 맨 위에 보여 주고 바로 고칠 수 있게 한다(주소 + 변경).
- P3 코드는 자릿수 칸으로 받고, 다시 받기는 글자 버튼 + 남은 시간으로 둔다. 큰 버튼은 "확인" 하나만.
- P4 주 버튼은 칸이 다 차야 눌린다(그 전엔 흐리게). 무엇이 비었는지는 칸 자체로 보인다.
- P5 서류 올리기는 빈 상태 카드 안에 올리는 길(사진 찍기 · 파일 고르기)을 두고, 올린 뒤엔 파일 이름 줄 + 지우기로 바뀐다. 어떤 서류면 되는지 짧은 목록을 곁에 둔다.
- P6 고를 수 있는 값이 적으면(학적 상태 · 소득 구간 · 기준 연도) 펼치는 목록 대신 칩으로 한눈에 보인다.
- P7 메일이 없는 사람을 위한 다른 길(증명서 올리기)을 작은 글자 링크로 남긴다.
