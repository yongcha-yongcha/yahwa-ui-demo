## 관습 패턴 (따를 것)
- 사진 → 이름 → 기본 사실 한 줄 → 소개/취향 순서.
- 기본 사실은 작은 아이콘 + 값. 라벨은 생략하거나 아주 작게.
- 정보가 많으면 소제목으로 묶고 일부는 접는다.

## 고유 표현 (가져오지 않을 것)
- 각 앱 브랜드 색(분홍, 노랑, 보라, 빨강), 칩 모양과 테두리 스타일, 아이콘 세트, 문구("My work:", "Looking for"), 평점·리뷰 숫자 카드 구성.

## 창작 모드 · 다른 분야 영감 (야화 컨셉용)
- 필름 사진의 **날짜 각인**(주황 숫자)과 **컨택트 시트**의 프레임 번호 → 기본 사실을 필름 프레임 정보처럼.
- 일본 청춘영화의 **엔드 크레딧 / 캐스팅 표** → "역할 ○○ · 하늘" 같은 세로 크레딧 리듬.
- **학생증 · 도서 대출 카드 · 박물관 라벨** → 작은 표 안에 손글씨로 채운 사실.
- **영화 티켓 · 포스터 사양 문구**(상영시간 · 등급) → 키·성격을 작은 스펙 줄로.
- **교환일기 · 자기소개 카드(プロフィール帳)** → 손으로 쓴 '나에 대해' 칸, 스티커처럼 붙은 해시태그.
