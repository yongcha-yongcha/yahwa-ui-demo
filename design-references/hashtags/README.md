## 관습 패턴 (따를 것)
- 칩 한 종류를 눌러 켜고 끔. 고른 칩은 채움 + 체크.
- 몇 개 골랐는지/몇 개까지인지는 아래 행동 영역에.
- 선택 사항이면 건너뛰기를 주요 버튼과 같은 줄에.
- 목록이 길면 처음엔 일부만, "더 보기"로 펼침.

## 고유 표현 (가져오지 않을 것)
- 각 앱의 브랜드 색(주황, 검정 채움, 노랑), 이모지 아이콘 칩, 앱 마스코트, 문구.
