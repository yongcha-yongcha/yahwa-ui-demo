# 리프 충전 확인 시트 · 레퍼런스

- 브리프: 리프 묶음을 고른 뒤 뜨는 확인 바텀 시트. 보유 · 충전 · 합계 · 가격을 같은 위계로 깔끔하게. iOS 앱 결.
- 모드: 사용성 · 실행: 간단(8개, 스크린샷 저장과 점수표 생략).
- 본 화면(Mobbin iOS, 검색 "purchase coins confirmation", "confirm purchase bottom sheet summary total"): 자전거 대여 이용권 결제 시트, 송금 앱 구매 확인 시트 2종(단건 · 정기), 주식 주문 완료 요약, 게임형 코인 묶음 목록, 코인 구매 확인(잔액 부족 → 충전), 배달 주문 요약, 카페 주문 확인.

## 관습 패턴 (따름)
- 이름–값 표 + 결론 줄 굵게 + 구분선 (P2 · P3) — 대부분 화면 공통
- 시트 맨 아래 주요 버튼 하나 (P7)
- 잔액 부족을 확인 시트 안에서 알리고 충전으로 연결 (P6) — 코인 구매 확인

## 고유 표현 (가져오지 않음)
- 앱별 브랜드 색 버튼, 큰 금액 히어로 숫자, 코인 그림 · 일러스트, 약관 긴 문단

## 시트가 아닌 방식 (추가)
- 본 화면(검색 "select coin package total price buy button", "review order full screen pay button summary"): 투자 계획 확인 전체 화면, 광고 결제 확인 화면, 쇼핑 결제 화면(버튼 안 금액), 예약 결제 화면(아래 고정 바), 커뮤니티 코인 묶음 고르기(타일 선택 + 결과 문장 + 버튼), 코인 묶음 목록, 금액 입력형 구매 2종.
- 관습: 아래 고정 주요 버튼, 선택 테두리, 표 + 합계. 고유(가져오지 않음): 브랜드 색 버튼, 큰 금액 숫자 히어로, 코인 그림.
