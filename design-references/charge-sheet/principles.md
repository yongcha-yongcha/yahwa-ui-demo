# 리프 충전 확인 시트 · 원칙 (간단 벤치마킹, 2026-11-18)

사용성 모드. 결제 · 구매 확인 시트 8개를 보고 공통으로 쓰는 이유를 정리했어요.

- **P1 · 확인 시트는 세 덩어리** — 무엇을 하는지 제목 한 줄 → 이름–값 표 → 버튼 하나(+ 닫기/취소). 큰 숫자, 그림, 장식으로 시선을 끌지 않아요. 이미 앞 화면에서 고른 걸 "확인"만 하는 자리라서요.
- **P2 · 표의 줄은 모두 같은 위계** — 왼쪽 이름은 회색, 오른쪽 값은 진한 색, 같은 크기 · 같은 굵기, 오른쪽 정렬, 숫자는 자릿수 맞춤. 한 줄만 크거나 작으면 그 줄이 "다른 종류의 정보"처럼 읽혀요.
- **P3 · 결론 줄만 굵게, 위에 구분선** — 마지막에 사용자가 실제로 받는 것 · 내는 것(합계, 결제 금액)만 굵게 하고 그 위에 얇은 선을 그어 "여기까지 더하면 이것"을 보여 줘요. 크기는 그대로, 굵기로만 구분.
- **P4 · 순서는 지금 → 더하는 것 → 결과 → 내는 돈** — 보유, 충전, 보너스처럼 더해지는 걸 먼저 늘어놓고 결과를 아래에. 사람이 머릿속으로 더하는 순서와 같게.
- **P5 · 단위는 값에 붙여 한 번만** — "95리프"처럼 값 쪽에 단위. 아이콘을 줄마다 반복하지 않아요.
- **P6 · 모자랄 때는 같은 자리에서 해결** — 잔액이 모자라면 다른 화면으로 보내지 않고, 확인 시트 안에서 모자란 만큼과 채울 방법을 바로 보여 줘요.
- **P7 · 버튼은 하나의 행동** — 주요 버튼 하나(충전하기), 나머지는 글자 버튼. 결제 금액을 버튼에 한 번 더 쓰는 경우도 많아요(마지막 확인).

## 시트가 아닌 방식 (2026-11-18 추가, 결제 · 묶음 선택 화면 8개)
- **P8 · 전체 화면 확인은 표를 그대로 키우기만** — 시트와 같은 이름–값 표, 같은 결론 줄. 화면이 넓어도 줄을 더 늘리지 않고, 주요 버튼은 아래에 고정해 엄지 자리에 둬요.
- **P9 · 목록 안에서 고르고 바로 결제** — 묶음을 누르면 그 묶음이 선택 테두리로 표시되고, 화면 아래 고정 영역이 결과(충전 후 리프 · 결제 금액)를 바로 보여 줘요. 확인 단계를 따로 띄우지 않아 탭이 하나 줄어요. 고르기 전에는 고정 영역이 없거나 꺼져 있어요.
- **P10 · 버튼 안에서 행동과 금액을 나눠 적기** — "결제하기 | 16,900원"처럼 왼쪽 행동 · 오른쪽 금액. 금액이 버튼에 있으면 위 표에서는 금액을 반복하지 않아도 돼요.
